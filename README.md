# 🌌 AETHER – Futuristic Landing Page

A modern, futuristic landing page designed with glassmorphism, smooth animations, and immersive UI interactions. Built using HTML, CSS, and JavaScript, this project showcases contemporary frontend design principles and engaging user experiences.

---

## ✨ Features

- 🌌 Futuristic user interface
- 🧊 Glassmorphism design
- 🎨 Gradient typography
- 🖱️ Interactive mouse parallax effects
- 📜 Scroll reveal animations
- 💡 Ambient glow background
- 📱 Responsive layout
- ⚡ Smooth user interactions

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

```bash

```

Open the project

Simply open **index.html** in your browser.
